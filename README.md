# YOUR BRAND — متجر تيشيرتات

## التشغيل
افتح `index.html` في Chrome أو أي متصفح.

## تعديل المنتجات
افتح `script.js` وستجد قائمة `products`.
مثال:
{ id: 1, name: "اسم التيشيرت", category: "basic", price: 500, image: "images/shirt1.jpg" }

- `name` اسم المنتج
- `price` السعر بالجنيه
- `category` إما `basic` أو `oversize`
- `image` مسار صورة المنتج

## تغيير رقم واتساب
في `script.js` غيّر:
phone="201000000000"
إلى رقم واتساب البراند بصيغة دولية بدون +.

## تغيير اسم البراند
ابحث عن `YOURBRAND` و `YOUR BRAND` في `index.html` وغيّرهم.

## تطويرات لاحقة
يمكن إضافة لوحة تحكم حقيقية، قاعدة بيانات، تسجيل دخول، دفع إلكتروني، شحن، كوبونات، وإدارة الطلبات.
