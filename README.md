# VYRO — متجر أزياء قابل للتوسع

متجر Front-end عربي RTL مبني بدون dependencies، ويحتوي على:

- واجهة متجر responsive بتصميم جريء.
- فلترة المنتجات وسلة مشتريات محفوظة في المتصفح.
- إنشاء حساب إجباري قبل إتمام الشراء.
- حفظ الطلبات وعرضها داخل لوحة الإدارة.
- إضافة وتعديل وحذف المنتجات وإدارة المخزون والظهور.
- تخزين مؤقت عبر `localStorage` ليس مناسبًا للإنتاج وحده.

## التشغيل
افتح `index.html` مباشرة، أو شغّل أي static server.

## لوحة الإدارة
افتح `admin.html`. كلمة المرور التجريبية الحالية موجودة في `admin.js` في الثابت `PASSWORD` ويجب تغييرها قبل النشر.

## ملاحظات الإنتاج
هذا الإصدار prototype يعمل بالكامل على المتصفح. لتحويله إلى متجر حقيقي: اربط تسجيل الدخول والطلبات بباك-إند وقاعدة بيانات، استخدم hashing لكلمة المرور، أضف بوابة دفع، تحقق server-side، وحماية صلاحيات الإدارة.

## التخصيص
- المنتجات الافتراضية في `script.js`.
- الألوان والتصميم في `style.css` و`admin.css`.
- بيانات الطلب في `script.js`، ويمكن استبدال localStorage بطلب API بسهولة.
